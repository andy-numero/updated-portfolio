# Andrea De Castro -- Portfolio Website

A personal portfolio website showcasing my background, skills, tools,
experience, projects, education, and resume as a Bachelor of Science in
Information Technology student.

## Features

-   Responsive portfolio layout
-   Light and dark theme toggle
-   Active-section navigation highlighting
-   Animated navigation underline and project image hover effects
-   Project gallery with replaceable image placeholders
-   Resume viewing and download links

## Setup

1.  Keep `index.html`, `style.css`, and `script.js` in the same folder.
2.  Add your profile photo and project images to the `images` folder
    using the filenames above.
3.  Place your resume PDF beside `index.html` and name it `resume.pdf`.
4.  Open `index.html` in a web browser.

## Customization

Replace the sample images with your own while keeping the same
filenames, or update their paths in `index.html`. Edit the website
content in `index.html` and its appearance in `style.css`.

**Note:** Some icons load from online libraries and may require an
internet connection.
